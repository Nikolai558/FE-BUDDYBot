# Discord Staff User Commands
## Check Users
`/staff check-users`

Runs `/give-role` for every member of the server (bots are skipped). Members who aren't linked on VATUSA are counted but not messaged. When it finishes, you get a summary of how many members are linked, not linked, and any the bot couldn't check.

Only one check can run at a time.

**Permission Requirements**
* `Manage Messages` and `Manage Channels`
